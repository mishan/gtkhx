GtkHx

The Flatpak repository for GtkHx, a Hotline client. Builds here are signed by its author, and update with the rest of your Flatpak apps.

Install

flatpak install --user https://dl.gtkhx.org/gtkhx.flatpakref

Or open gtkhx.flatpakref with your software center. The GNOME runtime comes from Flathub, which is added for you if it is missing.

Betas

flatpak install --user https://dl.gtkhx.org/gtkhx-beta.flatpakref

The beta channel also gets every stable release newer than the beta, so it is never behind.

Already have a GtkHx bundle installed?

A bundle installed from a release before this repository existed doesn't update from it. Remove it first; your settings and bookmarks stay:

flatpak uninstall com.nasledov.gtkhx

Single-file bundles

To install from a file instead: x86_64, aarch64; betas, x86_64, aarch64. Installed with flatpak install --user GtkHx-x86_64.flatpak, a bundle still updates from here.

Other files

  • gtkhx.flatpakrepo: the repository alone, for flatpak remote-add --user gtkhx https://dl.gtkhx.org/gtkhx.flatpakrepo
  • gtkhx.gpg: the signing key, fingerprint 52EA 6BE1 7DDA 3820 F9D2 7052 B2F3 E8C4 817C DACD
  • updates.json: the latest version on each channel
